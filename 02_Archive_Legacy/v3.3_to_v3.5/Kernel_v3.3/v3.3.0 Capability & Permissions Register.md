## 2\. Capability Issuance & Lease Lifecycle Invariants

- **Single-Use Capability Tokens:** Capability tokens are minted under serializable isolation and consumed atomically during mutation preparation.
- **Lease Margins:** Tool gateway requires an active coordinator lease margin of > 5,000 ms prior to executing any physical write.
- **Epistemic Gate:** Capability tokens for mutations cannot be issued unless supporting claims have passed M-0015 schema validation and M-0341 deterministic SHA-256 quote match.
- **Least-Privilege Token Allocation:** Agents receive capability tokens strictly scoped to their operational role. Read-plane workers (researcher, critical-analyst) cannot acquire mutation tokens under any circumstance.
