## 1\. EXECUTIVE SUMMARY & FOUNDATIONAL ENGINEERING THESIS

### 1.1 The Problem: Five Structural Failure Modes of Frontier LLMs

Deploying frontier autoregressive Large Language Models (LLMs) as autonomous coworkers across long-horizon legal, regulatory, and engineering workflows exposes five persistent structural failure modes:

| Failure Mode | Mechanistic Root Cause | Operational Manifestation<br> |
| --- | --- | --- |
| **Autoregressive Context Drift** | Attention degradation over long token sequences ("lost-in-the-middle"). | Silently dropping early negative constraints, formatting rules, and statutory boundaries. |
| --- | --- | --- |
| **Conversational Sycophancy** | RLHF alignment favoring agreeableness over empirical ground truth. | Validating flawed operator premises, unviable legal theories, or under-dimensioned calculations. |
| --- | --- | --- |
| **Silent Hallucination** | Probabilistic completion pressure across evidentiary voids. | Fabricating plausible-sounding statutory citations, gazette dates, or missing measurements. |
| --- | --- | --- |
| **State Amnesia** | Context resets, app switching, and unpersisted session crashes. | Multi-stage project collapse, forcing the operator to manually reconstruct task progress. |
| --- | --- | --- |
| **Payload Contamination** | Task parameters hardcoded into system-level prompt spaces. | Domain litigation facts bleeding into reusable skills, causing prompt injection and rule drift. |
| --- | --- | --- |

### 1.2 The Architectural Solution: Single-Kernel Monism

To permanently eliminate these failure modes, the architecture enforces **Single-Kernel Monism**:

- **Project Sentinel (The Sole Operating Substrate & Governance Kernel):** Project Sentinel is the singular system substrate, control plane, and invariant enforcement kernel. It maintains the canonical **35 Core Empirical Master Engines** (each bound 100% to a named falsifiable test probe PRB-\*), quarantines 226 descriptive cards in the Secondary Reference Layer, and maintains 1,560 staged proposals in isolated research repositories. It enforces hard epistemic truth floors, untrusted data quarantine envelopes, anti-sycophancy audits, and human-in-the-loop approval gates.
- **Project Optimus (The Multi-Agent Orchestration & Meta-Compiler Subsystem):** Subordinated strictly within Sentinel's execution plane, Optimus operates as a 4-layer hierarchical execution fleet of 7 specialized runtime agent skills backed by Sentinel's persistent 5-Register Google Drive Control Plane. It utilizes a **Meta-Compiler (prompt-architect)** with a **Two-Tier Cache Architecture** (Universal Frozen Substrate ~1,500 tokens + Modular Cluster Prefixes) to dynamically compile lean, task-specific prompts containing strictly **3 to 6 Core Master Engines** per role, coordinated via stigmergic state boards (\[STATE\_BOARD\]) under a strict single-item work-in-progress (WIP-1) lock.

- **Phase 3-to-Phase 2 Back-Edge Rule:** When critical-analyst uncovers an evidentiary gap in Phase 3, the coordinator routes directly back to researcher for targeted discovery before operator drafting.

The conflict is presented symmetrically with equal word counts under \[CLAIM\], \[EVIDENCE\], \[WHAT\_WOULD\_CHANGE\_MY\_MIND\], offering three operator choices: (R1) Evidentiary, (R2) Strategic-with-Flag, or (R3) Scope-Split. If the operator gives any subsequent directive without choosing, the system executes a **Synchronous Next-Turn Interrupt Default to (R3: Scope-Split)**, archiving the contested point and proceeding on verified ground.

### 5.2 Evidence Control Is Not a Drafting Privilege (\`M-0341\`)

- **Three-Tier Asymmetric Evidence Ledger:**
  - *Tier 1 (T1 — Verbatim Audit Floor):* Immutable full-text quotes directly supporting affirmative claims, verified via byte-exact string and SHA-256 hash checks.
  - *Tier 2 (T2 — Hash-Anchored Pointer):* Staged context carrying \[Q#\] + sha256 + 1-line locator. Default staging mode for researcher.
  - *Tier 3 (T3 — Summary Only):* High-level background orientation. Strictly banned from supporting affirmative claims.
- **Dual-Channel Pipeline:**
  - *Evidence Channel:* Raw, byte-exact, hash-locked string used strictly for reproduction into the deliverable and SHA-256 verification. Never exposed as instructions in reasoning prompts.
  - *Quarantine Channel:* Reversibly escaped text inside <untrusted\_data id=Q#> for inert semantic analysis in read-only posture.
- **Deterministic Verifier Hash Gate:** Quote verification in verifier-officer is a deterministic string/hash comparison, rendering prompt injection structurally incapable of forcing an unearned audit PASS.
- **Phase 4 Pre-Audit Grammatical Shape Linter:** Operator runs regex screening on numbers (), dates, statutory sections ($\\S$), and causal assertions lacking adjacent citations before verifier handoff, while passing rhetorical connectors and boilerplates cleanly.
