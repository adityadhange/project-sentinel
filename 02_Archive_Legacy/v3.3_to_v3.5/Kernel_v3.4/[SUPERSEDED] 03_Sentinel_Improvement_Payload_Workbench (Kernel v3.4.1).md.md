## 2\. Ingestion Lifecycle Protocol (M-0001 & Co-Developer Contract)

Whenever a new external advisory memo, architectural audit, benchmark result, or refactoring roadmap is provided:

1. **Stage & Isolate:** Treat the text strictly as an ephemeral input (\[IMPROVEMENT\_PAYLOAD: <ID>\]). Never allow unvetted suggestions to modify permanent prompt templates directly.
2. **Deterministic Pre-Screening:**
  - *Screen 1 (Falsifiable State Change):* Reject purely aspirational advice ("be more rigorous"). Accept only items defining observable file operations, token classes, numeric bounds, regex linters, or deterministic code checks.
  - *Screen 2 (Relevance & Capability Grounding):* Verify compatibility with native Gemini tool boundaries and the $0 budget ceiling.
3. **Mandatory Adversarial Audit:** Submit candidate change packages to critical-analyst for counter-argument steelmanning and opposing simulation before drafting proposals.
4. **Stage Standardized ACPs:** Package accepted items into formal \[ARCHITECTURE\_CHANGE\_PROPOSAL\] envelopes with falsifiable tests and rollback paths.
5. **Await Level D Ratification:** No live register or skill may be mutated until the Principal Operator confirms via APPROVE <ProposalID>.
