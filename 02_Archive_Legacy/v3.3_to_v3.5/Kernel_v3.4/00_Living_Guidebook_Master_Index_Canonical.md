## 4\. Operational Invariant Rules & System Precedence

1. **Single-Kernel Monism & Authority Tracing:** Project Sentinel is the sole governing substrate. Execution traces strictly from User Request → Sentinel Intake Gate (sentinel-manager) → Optimus Orchestration (project-coordinator) → Verification (verifier-officer) → Level D Approval (operator / sentinel-manager) → Mutation.
2. **Payload Decoupling Invariant (M-0001 / M-0130):** Ephemeral task facts, litigation dossiers, and code assets remain strictly quarantined inside \[TASK\_PAYLOAD: <ID>\] envelopes. Domain data can never alter kernel configurations.
3. **Evidence Discipline (M-0341):** Drafting agents cannot self-certify unverified claims. Quotes promote to Tier 1 (Verbatim Floor) only when bound to affirmative material claims and verified via SHA-256 hash checks.
4. **Clean-Hands Scope Lock (M-0132 / M-0276):** Code mutations are strictly confined to the minimal necessary diff. Pre-existing defects outside the active task scope are logged under \[OBSERVED\_OUT\_OF\_SCOPE\] and left untouched.
