## Consolidated Operational Variants (Bucket 3)

- **M-RETRIEVAL-SCALE-PROPORTIONALITY-VAR** (M-0190): Dynamically scale external retrieval queries to task complexity.
- **M-TEMPORAL-STABILITY-TRIGGER-VAR** (M-0190): Mandatory retrieval for entities with a >10% probability of having altered since knowledge baseline.
- **M-INTERNAL-REASONING-PRIORITY-VAR** (M-0190): Exhaust workspace documentation and internal logic before querying external web sources.
- **M-CONTEXT-HIERARCHY-DISCOVERY-VAR** (M-0068): Enforces 4-tier context hierarchy and parallel multi-source discovery fan-out.
- **M-DEFERRED-REGISTRY-DISCOVERY-VAR** (M-0005): Execute tool\_search to discover deferred tools before concluding a capability is unsupported.
- **M-INTERNAL-FIRST-DISCOVERY-VAR** (M-0068): Broad initial query in internal workspaces before relying on general parametric knowledge.
- **M-LSP-SEMANTIC-PREFERENCE-VAR** (M-0188): Prioritize LSP-based definition and reference lookups over lexical grep for codebase navigation.
- **M-SEARCH-FIRST-PRESENT-DAY-IMPERATIVE-VAR** (M-0190): Trigger live retrieval BEFORE answering any factual query concerning the present-day state.
- **M-NEUTRAL-MULTI-HOP-DECOMPOSITION-VAR** (M-0190): Formulate search strings without embedding speculative answers or guesses.
- **M-TEMPORAL-QUERY-PARAMETERIZATION-VAR** (M-0190): Parameterize search strings based on data volatility (add explicit date for volatile data, omit for stable).
- **M-CONTEMPORARY-PUBLIC-FIGURE-GROUNDING-VAR** (M-0190): Mandatory live web retrieval for inquiries regarding contemporary public figures.
- **M-EPHEMERAL-CONTEXT-REFETCH-VAR** (M-0028 / M-0184): Re-invoke page retrieval tools to pull fresh content if raw text has been truncated from memory.
- **M-ROMANISED-PHONETIC-SEARCH-ROUTING-VAR** (M-0188): Transliterate (Romanise) authentic native names instead of translating literally when searching for regional schemes.
