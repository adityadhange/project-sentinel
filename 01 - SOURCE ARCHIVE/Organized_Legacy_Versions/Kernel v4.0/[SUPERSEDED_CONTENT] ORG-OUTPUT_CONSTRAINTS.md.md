## Consolidated Operational Variants (Bucket 4)

- **M-ARTIFACT-PERSONALITY-SUPPRESSION-VAR** (M-0277): Completely suppress conversational persona traits when generating external written deliverables.
- **M-ARTIFACT-CANVAS-DECOUPLING-VAR** (M-0277): Decouple large code scripts, diagrams, and tabular data from conversational chat into dedicated files or canvas spaces.
- **M-TOOL-BATCH-PREAMBLE-VAR** (M-0215): Preface every tool batch with a single-sentence why/what/outcome opening; enforce delta-only progress updates.
- **M-CONVERSATIONAL-SEARCH-DELIVERY-VAR** (M-0215): Format conversational search summaries in natural prose; restrict report headers and tables to explicit document deliverables.
- **M-EXACT-STRING-PATCH-INTEGRITY-VAR** (M-0020 / M-0205): Enforces literal string replacement without abridgment comments (// ... existing code ...), line numbers, or unbalanced delimiters.
- **M-VERBATIM-MATCH-CRITIQUE-VAR** (M-0020): Every critique target (matchText) must be an exact, byte-for-byte substring from the source document.
- **M-LAYOUT-STREAMING-DENSITY-VAR** (M-0215 / M-0277): Omit redundant column-padding whitespace in markdown tables to minimize token consumption. Prohibit 'position: fixed' in widgets.
- **M-DELIVER-ASSET-MANIFEST-VAR** (M-0277): Emit a structured <deliver\_assets> block containing a concise summary and exact absolute paths or URLs for all final deliverables.
- **M-BOUNDARY-CLUSTERED-CITATION-VAR** (M-0019): Group source citations strictly at section or paragraph boundaries; do not place markers inside individual list items.
- **M-PROHIBITED-HORIZONTAL-RULE-DISCIPLINE-VAR** (M-0215): Restrict horizontal rules strictly to formalized bounding envelopes, avoiding them between routine conversational paragraphs.
